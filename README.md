# 数III 微積ノート（Math III Calculus Interactive）

高校数学IIIの微分・積分を、**動くグラフ・ステップ式公式導出・インタラクティブ計算ドリル・赤シート公式集**で本質から理解し、定期テストの得点力を高めるスマホ最適化Webアプリです。

## 主な特徴

- **全5章・20トピックの体系的カリキュラム**（1トピック10〜20分）
  1. 第1章：関数の極限と連続性
  2. 第2章：微分法
  3. 第3章：微分法の応用
  4. 第4章：積分法
  5. 第5章：積分法の応用
- **8種類の動く視覚シミュレーター**（単位円 $\sin x / x$、自然対数の底 $e$、割線→接線＆9倍ズーム、平均値の定理、増減・凹凸・変曲点ライブ解析、置換積分の面積保存、回転体3D断面スライス、区分求積法）
- **丸暗記を防ぐタップ展開式の公式導出ステップ**
- **計算トレーニングドリル**（厳選35問＋無限ランダム生成ドリル、選択式／紙ペン演習モード切替、2段階ヒント、苦手リトライ）
- **テスト直前・赤シート暗記モード付き公式まとめ**
- **スマホ片手操作最優先UI**＆`localStorage` による進捗自動保存（アカウント登録不要）

## ローカル開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`main` ブランチへプッシュすると、`.github/workflows/deploy.yml` によって自動的に GitHub Pages へデプロイされます。
